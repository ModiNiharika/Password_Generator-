# Password Generator 
A Python project that generates secure random passwords with customizable options such as numbers, symbols, and password strength checking.

## Features
* Generate secure random passwords
* Choose how many passwords to generate
* Choose password length for each password
* Option to include numbers
* Option to include symbols
* Password strength checker
* Copy password to clipboard

## Technologies Used
* Python
* Random Module
* String Module
